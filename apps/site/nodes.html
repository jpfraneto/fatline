Every node, measured.

Farcaster lives on independent nodes: Snapchain, run by Farcaster's validators, and Hypersnap, a community fork. Here are the ones that joined Fatline, the clients that read them, and who runs each. Every node is measured once an hour against reference nodes: in sync, catching up, or not answering. Nobody's word for it.

For developers

The same list, as JSON. Filter by network, or only nodes in sync right now:

curl 'https://fatline.ink/api/registry?network=snapchain&healthy=true'
curl 'https://fatline.ink/api/registry/<id>'      # one node, with its last 48 measurements

Then talk to the node itself. Fatline never sits between your app and the node.

health.statesynced: answers, every shard within 600 blocks of the reference, and returns casts it is asked for by hash. behind: answers, further back. invalid: answers, not like a Farcaster node. unreachable: no answer. unknown: not measured yet. stale: the last measurement is over 2.5 hours old.
networksnapchain or hypersnap, measured (Hypersnap answers its /v2 user API), not taken from the record.
proof.methodegg: a Fatline place, its keeper's signed egg names the node. well-known: the host serves /.well-known/fatline with the operator's FID. dns: a TXT record at _fatline.<host>.
measuredByThe server that measured. Every Fatline server runs its own registry at /api/registry and measures from where it stands: ask more than one.

The records live on Farcaster

A node joins with one cast whose parent is https://fatline.ink/nodes:

fatline node
node: https://hub.example.com:3381
client: https://example.com          (optional, a client that reads it)
name: Example                        (optional)

Any node holds them, so you can read the list without Fatline: GET <any node>/v1/castsByParent?url=https://fatline.ink/nodes. Delete the cast and the node leaves. A record counts only when its host proves it (above); a claim on someone else's node is not listed.
